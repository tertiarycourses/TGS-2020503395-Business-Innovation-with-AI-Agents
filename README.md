# TGS-2023039340 - Microsoft Power Platform Developer (PL-400)

> **Course:** WSQ - Microsoft Power Platform Developer (PL-400)  
> **Course Code:** TGS-2023039340  
> **Register here:** https://www.tertiarycourses.com.sg/wsq-microsoft-power-platform-developer-pl-400.html

These are the hands-on lab exercises for the WSQ Microsoft Power Platform Developer (PL-400) course delivered by [Tertiary Infotech Academy Pte Ltd](https://www.tertiarycourses.com.sg/).

This repository contains **10 guided developer labs** aligned to the Microsoft PL-400 exam skills measured. The labs cover technical design, Dataverse security, solutions and ALM, Power Platform CLI, environment variables, pipelines, canvas app Power Fx, model-driven app client scripting, PCF code components, plug-ins, custom APIs, custom connectors, Dataverse Web API, Azure Functions, cloud flows, service endpoints, change tracking, alternate keys, and exam readiness.

## How to use

1. Read the learner guide first to understand the Contoso service management case study.
2. Open each lab and complete the steps in order.
3. Use a Power Platform developer environment or trainer-provided tenant for hands-on activities.
4. Save outputs as solution notes, screenshots, code snippets, command logs, diagrams, or checklists.
5. Review the checkpoint questions at the end of each lab.
